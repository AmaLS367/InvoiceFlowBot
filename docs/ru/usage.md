## 📋 О боте

> [!TIP]
> Начните с команды `/start`.

## Стандартный сценарий

1. Введите `/start` и выберите один из семи языков: русский, английский, немецкий, испанский, французский, итальянский или португальский. Бот использует сохранённый выбор, затем язык Telegram, если он поддерживается, затем русский.
2. Загрузите PDF, JPEG, PNG, WebP или фото через Telegram. Перед загрузкой преобразуйте HEIC/HEIF в JPEG или PNG.
3. После OCR бот автоматически покажет черновик и может приложить CSV для длинной таблицы позиций. Команда `/show` покажет черновик повторно.
4. Проверьте отмеченные значения и исправьте шапку или существующие позиции. При необходимости добавьте комментарий.
5. Сохраните счёт через `/save` или кнопку сохранения. Если сумма позиций отличается от итога счёта, бот запишет об этом комментарий.
6. Запросите сохранённые счета через `/invoices` или кнопку запроса за период.

## Команды

- `/start` — открыть выбор языка и главное меню.
- `/help` — показать доступные действия.
- `/language` — открыть список языков, он также доступен через кнопку **🌐 Язык**. В личном чате выбор обновляет меню команд.
- `/show` — показать текущий черновик.
- `/save` — записать счёт в SQLite и удалить черновик.
- `/edit supplier=ACME; client=Corp; date=2025-01-15; doc=123; total=123.45` — изменить несколько полей шапки. Разделяйте параметры точкой с запятой.
- `/edititem 1 name=Widget; qty=5; price=10.50; total=52.50` — изменить позицию. Нумерация начинается с 1. Можно также указать `code`.
- `/comment <text>` — добавить комментарий к текущему черновику.
- `/invoices YYYY-MM-DD YYYY-MM-DD [supplier=text]` — получить сохранённые счета за период с необязательным фильтром по поставщику.

## Интерактивные кнопки

Через меню можно получить подсказку по загрузке, отредактировать шапку или существующие позиции, добавить комментарий, сохранить черновик, открыть справку, выбрать язык и запросить счета за период. Для названия поставщика с пробелами используйте кнопку запроса за период.

## Работа с черновиком

SQLite хранит один активный черновик на пользователя Telegram. Новый успешно обработанный файл заменяет текущий черновик. После сохранения загрузите следующий счёт, чтобы начать новый черновик.

Черновик и язык привязаны к пользователю. Запрос за период ищет среди всех сохранённых счетов экземпляра бота и фильтрует их по датам и поставщику.
